# Example observation: changing temperature

**Fictional teaching example. No experiment described here was performed.**

## Observation

In this invented pilot, I compared a temperature sensor with a reference thermometer. Their difference increased while the room warmed. Both elapsed time and room temperature changed during the session.

## Interpretation and uncertainty

I initially called the change [sensor drift](/concepts/example-concept.md). That was an interpretation, not an established mechanism. Temperature dependence, sensor warm-up, and changes in the reference remain possible explanations. The pilot cannot distinguish them because time and temperature varied together.

This observation motivates the [sensor comparison project](/entities/example-project.md). Compare it with the [fixed-temperature observation](/sources/example-fixed-temperature-observation.md); the [analysis](/analyses/example-analysis.md) considers what each can establish.
