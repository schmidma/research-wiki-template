# Zotero Import

Import the document as a clean bibliographic parent with a Zotero-managed file attachment.

## Workflow

1. Inspect the document and identify its title, creators, date, type, venue, and publication status.
2. Search the target library for duplicates using the title, identifier, author/year, and filename as appropriate.
3. Build metadata from evidence in the document and authoritative external sources. Do not invent missing publication details.
4. Create the bibliographic parent, then import the source file as a stored child attachment—never a linked file unless explicitly requested.
5. Verify the parent metadata, child relationship, and Zotero-managed storage path. Compare the stored copy with the source when useful.
6. Report the item, attachment, citation key if available, and any unresolved metadata.

## Judgment

- Preserve author order and distinguish authors from affiliations, funders, or project partners.
- For accepted or in-press papers, record the confirmed venue and status but omit DOI, pages, and final proceedings details until known.
- Let Zotero or Better BibTeX generate the citation key unless the user asks to set it.
- If a likely duplicate exists, stop and ask how to handle it.
- If an attachment succeeds but is briefly absent from Zotero’s child index, verify storage and retry the read once rather than uploading again.
- Preserve the source file and keep the user informed before writes and at meaningful milestones.
