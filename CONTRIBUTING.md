# Contributing

Contributions that make this template more useful to researchers are welcome.
That includes clearer instructions, better examples, fixes to the checker,
and ideas from using the template in your own research.

## Ideas and questions

Open an issue if something is confusing, missing, or not working as expected.
Explain what you were trying to do and where the template fell short.

For substantial changes to the research workflow or tooling, start a
conversation before investing in an implementation. The aim is a useful
starting point that researchers can adapt, not a framework for every
possible workflow.

## Pull requests

Describe the problem your change addresses and why the proposed solution
helps. Small, focused improvements are easier to discuss and review.

Use fictional or appropriately shareable examples. Do not include private
research material, credentials, or personal library identifiers.

For checker changes, include a small test when it helps protect the affected
behavior. For documentation and example changes, check that the instructions
and links work. See the [README](README.md) for getting started.
